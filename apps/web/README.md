# web

Next.js (App Router) frontend for [Overloaded](../../README.md).

See the [root README](../../README.md) for architecture, routes, and setup instructions.

## Scripts

| Script | Description |
|---|---|
| `pnpm dev` | Start the dev server at `http://localhost:3000` |
| `pnpm build` | Build a static export |
| `pnpm start` | Serve the production build |
| `pnpm lint` | Lint |
| `pnpm format` | Format with Prettier |
